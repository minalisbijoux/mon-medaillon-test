Gravure du Soleil

Hauteur de référence : 2,5 mm. Les textes courts peuvent être agrandis. Vous pouvez écrire librement : une ligne trop longue apparaît en rouge et empêche la validation. En mode deux lignes, les deux lignes sont vérifiées indépendamment avec la même limite géométrique.

Restaurer une sauvegarde

Importe un fichier JSON exporté depuis cette application. Les commandes déjà présentes sont conservées ; aucun doublon n’est ajouté.

Transfert vers le Mac — essai réseau local

Sur le Mac, démarrez le récepteur fourni dans le dossier « Mac — réception ». Renseignez son adresse Wi-Fi et son code. L’application essaie ensuite d’envoyer les commandes en attente, sans supprimer les copies sur l’iPad. Ce transfert dépend des autorisations réseau de Safari et doit être testé.
